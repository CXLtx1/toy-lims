# LIMS 滴定公式整理

> 本文根据实验室提供的 13 页公式资料重新整理，仅作为 LIMS 方法设计稿，不写入数据库。正式启用前仍需逐项与现行标准、SOP、标准溶液标定方式和终点定义核对。

## 1. 设计原则

LIMS 已保存下列前处理信息：

- 样品称样量 `m`（g）
- 初次定容体积 `Vprep`（mL）
- 后续分取、定容形成的总稀释倍数 `D`

因此，滴定方法不应再次使用 `m`、`Vprep` 和 `D` 直接计算样品质量分数。滴定公式只计算**被滴定溶液中的待测组分浓度**，再由 LIMS 使用统一公式换算原样结果。

### 固体样品统一换算

滴定方法输出溶样浓度 `Csol`（mg/L）后：

```text
w(%) = Csol * Vprep * D / (m * 10000)
```

### 液体样品统一换算

```text
Csample(mg/L) = Csol * D
```

### 当前程序限制

当前 LIMS 的 `function` 方法会直接把公式值当成 `%`，不会再套用称样、定容和稀释换算。本文公式若要正式使用，计算引擎应先支持以下输出类型：

1. `concentration_mg_l`：公式输出当前待测液的 mg/L，再走固体或液体统一换算。
2. `concentration_mol_l`：公式输出当前待测液的 mol/L，用于 H+、OH- 等项目；液体样仍应乘系统记录的稀释倍数。
3. `direct_percent`：确实只能直接得到原样质量分数时使用；不应作为常规滴定方法的默认模式。

在引擎完成上述区分前，**不要把本文浓度公式直接录入现有 `function` 方法**。

## 2. 通用变量

| 变量 | 含义 | 单位 |
|------|------|------|
| `c` | 标准滴定溶液物质的量浓度 | mol/L |
| `V` | 样品消耗标准液体积 | mL |
| `V0` | 空白消耗标准液体积；无空白时填 0 | mL |
| `Vs` | 实际参加滴定的待测溶液体积 | mL |
| `M` | 报告组分的摩尔质量 | g/mol |
| `k` | 1 mol 滴定剂对应的报告组分物质的量 | mol/mol |

对于普通直接滴定，溶液浓度通式为：

```text
Csol(mg/L) = (V - V0) * c * k * M * 1000 / Vs
```

说明：

- `Vs` 是从当前溶样或稀释液中实际移取参加滴定的体积，不是初次定容体积。
- LIMS 已记录的稀释倍数不得再写入方法公式，避免重复换算。
- 空白方向必须按方法确定。通常直接滴定用 `V - V0`；返滴定和 COD 常用 `V0 - V` 或“加入量减剩余量”。
- 标准液若以当量浓度 `N` 标定，不能直接当作 mol/L 的 `c` 使用。

## 3. 可直接整理为浓度公式的方法

以下公式均以滴定所得待测液浓度为输出，不直接输出原样 `%`。

### 3.1 铜：碘量法

反应当量：1 mol Na2S2O3 对应 1 mol Cu。

```text
C_Cu = (V - V0) * c * 63.546 * 1000 / Vs
```

建议 LIMS 公式：

```text
(V-V0)*c*63.546*1000/Vs
```

输出：`concentration_mg_l`。

### 3.2 锌：EDTA 络合滴定

EDTA 与 Zn 按 1:1 络合。

```text
C_Zn = (V - V0) * c * 65.38 * 1000 / Vs
```

建议 LIMS 公式：

```text
(V-V0)*c*65.38*1000/Vs
```

输出：`concentration_mg_l`。

### 3.3 氯离子：硝酸银滴定

Ag+ 与 Cl- 按 1:1 反应。

```text
C_Cl = (V - V0) * c * 35.45 * 1000 / Vs
```

建议 LIMS 公式：

```text
(V-V0)*c*35.45*1000/Vs
```

输出：`concentration_mg_l`。

### 3.4 钙：EDTA 络合滴定

EDTA 与 Ca 按 1:1 络合。根据报告组分选用不同质量系数：

| 报告组分 | 质量系数 `M` | 建议公式 |
|----------|--------------|----------|
| Ca | 40.078 | `(V-V0)*c*40.078*1000/Vs` |
| CaO | 56.077 | `(V-V0)*c*56.077*1000/Vs` |
| CaCO3 | 100.086 | `(V-V0)*c*100.086*1000/Vs` |
| Ca(OH)2 | 74.093 | `(V-V0)*c*74.093*1000/Vs` |

输出均为 `concentration_mg_l`。四个报告组分应建成四个明确的方法或一个带固定报告系数的方法，不建议让操作者临时填写 `M`。

### 3.5 铁：EDTA 络合滴定（当前已有）

EDTA 与 Fe 按 1:1 络合。

```text
(V-V0)*c*55.845*1000/Vs
```

输出：`concentration_mg_l`。

### 3.6 铁：重铬酸钾滴定（当前已有）

1 mol Cr2O7(2-) 对应 6 mol Fe(II)。

```text
(V-V0)*c*6*55.845*1000/Vs
```

输出：`concentration_mg_l`。

### 3.7 三氧化二铝：EDTA 络合、硫酸铜返滴定

返滴定必须分别记录 EDTA 加入量和 CuSO4 返滴量：

| 变量 | 含义 |
|------|------|
| `cE`、`VE` | EDTA 浓度和加入体积 |
| `cCu`、`VCu` | CuSO4 浓度和返滴体积 |
| `Vs` | 参加测定的待测液体积 |

Al2O3 的摩尔质量为 101.96 g/mol，1 mol Al2O3 含 2 mol Al，因此每 mol 净耗 EDTA 对应 50.98 g Al2O3：

```text
C_Al2O3 = (cE*VE - cCu*VCu) * 50.98 * 1000 / Vs
```

建议 LIMS 公式：

```text
(cE*VE-cCu*VCu)*50.98*1000/Vs
```

输出：`concentration_mg_l`。

若两种标准液浓度相同，可简化为 `(VE-VCu)*c*50.98*1000/Vs`，但不建议在系统中假定浓度永远相同。原资料只给一个 `c` 和一个消耗体积，不能完整表达返滴定过程。

## 4. 酸碱及氧化还原滴定

### 4.1 氢离子浓度

用 NaOH 滴定，输出待测液 H+ 的 mol/L：

```text
C_H = (V - V0) * c / Vs
```

建议 LIMS 公式：

```text
(V-V0)*c/Vs
```

输出：`concentration_mol_l`，单位 mol/L。此结果不能再套用固体质量分数公式。

### 4.2 氢氧根离子浓度

用 HCl 滴定，输出待测液 OH- 的 mol/L：

```text
C_OH = (V - V0) * c / Vs
```

输出：`concentration_mol_l`，单位 mol/L。

### 4.3 盐酸（以 HCl 计）

HCl 与 NaOH 按 1:1 反应：

```text
(V-V0)*c*36.46*1000/Vs
```

输出：`concentration_mg_l`。

### 4.4 硫酸（以 H2SO4 计）

完全中和时 1 mol H2SO4 消耗 2 mol NaOH，因此使用硫酸的当量质量 `98.079/2`：

```text
(V-V0)*c*(98.079/2)*1000/Vs
```

输出：`concentration_mg_l`。

### 4.5 氢氧化钠（以 NaOH 计）

NaOH 与 HCl 按 1:1 反应：

```text
(V-V0)*c*39.997*1000/Vs
```

输出：`concentration_mg_l`。

### 4.6 碳酸钠（以 Na2CO3 计）

若滴定至完全中和终点，1 mol Na2CO3 消耗 2 mol HCl，应使用 `105.988/2 = 52.994`：

```text
(V-V0)*c*(105.988/2)*1000/Vs
```

输出：`concentration_mg_l`。

原资料直接使用 105.98，只有在 `c` 实际表示酸的当量浓度、采用不同终点，或方法另有系数定义时才可能成立。启用前必须核对 SOP 的终点和浓度定义。

### 4.7 氨（以 NH3 计）

NH3 与 HCl 按 1:1 反应：

```text
(V-V0)*c*17.031*1000/Vs
```

输出：`concentration_mg_l`。

### 4.8 次氯酸钠（以 NaClO 计）

碘量法中 1 mol NaClO 对应 2 mol Na2S2O3，因此每 mol Na2S2O3 对应 37.221 g NaClO：

```text
(V-V0)*c*37.221*1000/Vs
```

输出：`concentration_mg_l`。

这与“有效氯（以 Cl2 或 Cl 计）”不是同一报告口径，必须使用不同方法名和质量系数。

### 4.9 有效氯（当前已有）

若按有效氯质量（以 Cl2 当量计），每 mol Na2S2O3 对应 35.45 g 有效氯：

```text
(V-V0)*c*35.45*1000/Vs
```

输出：`concentration_mg_l`。报告名称必须明确写“有效氯”，不能写成 NaClO 含量。

### 4.10 过氧化氢：高锰酸钾法

必须先确认高锰酸钾标准液使用**物质的量浓度**还是**当量浓度**。

若 `c` 为 KMnO4 的 mol/L，酸性条件下 1 mol KMnO4 对应 2.5 mol H2O2：

```text
(V-V0)*c*2.5*34.0147*1000/Vs
```

若 `N` 为当量浓度，则使用 H2O2 的当量质量 17.007：

```text
(V-V0)*N*17.007*1000/Vs
```

两式不能混用。原资料写“KMnO4 mol/L”却使用 17.01，当量定义不一致；正式启用前必须确认，否则结果可能相差 5 倍。

## 5. 水样浓度方法

### 5.1 化学需氧量：重铬酸钾法

COD 本身报告为水样 mg/L。公式只计算当前参加测定的水样溶液浓度，系统记录的样品稀释倍数仍由 LIMS 统一处理：

```text
C_COD = (V0 - V) * c * 8000 / Vs
```

变量：

- `V0`：空白消耗硫酸亚铁铵体积，mL
- `V`：样品消耗硫酸亚铁铵体积，mL
- `c`：硫酸亚铁铵标准液浓度，mol/L
- `Vs`：回流时取水样体积，mL
建议 LIMS 公式：

```text
(V0-V)*c*8000/Vs
```

输出：`concentration_mg_l`。液体样最终结果由 LIMS 再乘系统记录的 `D`；没有稀释时 `D=1`。原资料中的 `f` 不进入方法公式，避免与样品前处理重复。

## 6. 暂不建议直接配置的方法

### 6.1 铬：标样体积比法

原资料公式为：

```text
w(Cr) = 58.37% * Vsample / Vstandard
```

这不是独立的化学计量公式，而是以 58.37% 铬标样为单点校准。它只有在标样与样品称样量、定容体积、分取体积和处理过程完全一致时才成立。

若要纳入 LIMS，应至少补充：

- 标样实际称样量及证书值
- 标样和样品各自定容、分取体积
- 空白校正方向
- 硫酸亚铁铵标定方式

资料不足前不要配置为通用方法。

### 6.2 分光、比浊和称量方法

以下项目不是滴定方法，不应放入本滴定方法模块：

- 磷：铋盐-钼蓝分光光度法
- 铜：分光光度法
- 镍：丁二酮肟分光光度法
- 氯离子：比浊法
- 水分称量法（应继续使用专项检测模块）
- 总氮仪器测定

如后续需要，可另建“标样比值法/分光光度法”方法类型，明确标准浓度、标准取样体积、样品取样体积和吸光度变量。

## 7. 按资料要求不处理的公式

原资料已标注“不用添加”的项目不进入本方案：

1. 仪器直接测浓度的通用元素公式
2. 煤样灰分
3. 煤样挥发分
4. 固定碳
5. 水样中元素浓度通用稀释公式

这些项目已由 LIMS 的仪器浓度换算、专项检测或样品稀释模型处理。

## 8. 建议的 LIMS 方法字段

为避免再次混淆“溶样浓度”和“原样结果”，每个滴定方法至少应保存：

| 字段 | 示例 |
|------|------|
| 方法名称 | `Zn-EDTA络合滴定` |
| 公式 | `(V-V0)*c*65.38*1000/Vs` |
| 输出类型 | `concentration_mg_l` |
| 输出单位 | `mg/L` |
| 固定常数 | `{}` 或明确的质量系数 |
| 变量中文名及单位 | `V=样品滴定体积(mL)` 等 |
| 反应计量说明 | `EDTA:Zn = 1:1` |
| 空白方向 | `V-V0`、`V0-V` 或返滴定净耗 |
| 适用标准/SOP | 实验室现行文件编号及版本 |

推荐使用 `Vs` 统一表示参加滴定的待测液体积；`Vprep`、`m` 和样品稀释倍数由 LIMS 自动取得，不出现在浓度公式中。

## 9. 启用前核对清单

每个方法正式加入数据库前必须确认：

1. 标准液浓度是 mol/L 还是当量浓度。
2. 空白扣除方向正确。
3. 化学计量系数及报告口径正确，例如 Ca、CaO、CaCO3、有效氯和 NaClO 不可混用。
4. `Vs` 确实是参加滴定的待测液体积。
5. 方法内部没有重复乘入 LIMS 已记录的定容体积或稀释倍数。
6. 固体样用统一质量分数换算，液体样用统一浓度换算。
7. 至少使用一个有证标准样和一个人工计算案例核对结果。
8. SOP、方法名称、报告组分和单位完全一致。
