# 滴定方法与公式引擎实现说明

> 本文描述系统中**实际实现**的滴定（公式方法）机制，依据当前代码整理，不是设计稿。
> 代码位置：`server/app.py`（公式引擎、结果计算）、`server/db_schema.py`（内置方法种子）、`server/static/app.js`（录入界面）。

## 1. 核心模型

滴定方法在系统中称为 `function` 类型方法，本质是一个**安全的算术公式**：

- 公式直接输出**原样质量分数 %**，系统不再追加任何换算。
- 公式中的变量来自三个来源（见第 3 节）：操作者按读数录入、方法固定常数、溶样方案的称样量/定容体积。
- 每一遍读数独立保存自己的变量值（`readings.extra` JSON），因此平行样的 `V`、`V0`、`c` 等各自独立。

数据流：

```text
数据页录入 (V/V0/c…) → readings.extra(JSON, 每读数一份)
    → reading_value()：代入公式逐读数求值 (%)
    → calc_result()：勾选"参与"的读数取平均 → ×回标系数 → 保留4位小数
    → 报告 / Excel / 结果页（同一份 payload）
```

## 2. 公式引擎

### 2.1 允许的语法

公式保存和求值都用 Python `ast` 白名单实现（`formula_variables` app.py:234、`special_formula_value` app.py:216）：

| 允许 | 不允许 |
|------|--------|
| 数字（int/float） | 函数调用、属性访问 |
| 变量名（字母/下划线开头，≤32 字符） | 字符串、布尔、列表 |
| 运算符 `+ - * / **` 和一元 `+ -` | 取模 `%`、整除 `//`、比较、位运算 |
| 括号改变优先级 | 任何非白名单语法 |

限制：公式 ≤500 字符，变量 ≤30 个。语法不符保存时即拒绝（"公式只允许变量、数字、括号和 + - * / ** 运算"）。

引擎不 eval 原始字符串，只对白名单 AST 求值，公式无法执行任意代码。

### 2.2 求值规则

- 变量**区分大小写**：`V` 和 `v` 是两个变量。
- 除以 0 → 该读数显示"公式错误: …"，不产生数值。
- 结果非有限数（NaN/inf）→ 同样报错。
- 求值结果**不做科学计数或量纲检查**，直接当作 %。

## 3. 变量来源与优先级

`reading_value()`（app.py:304）对每个读数构造变量环境，来源与覆盖顺序：

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1（最低） | 溶样方案固定值 | `m` = 溶样称样量(g)，`v` = 溶样定容体积(mL)。`METHOD_FIXED_VARS = {"m","v"}`，仅当溶样中确实填写了该值时注入 |
| 2 | 方法固定常数 | `methods.constants` JSON，如 `{"M": 65.38}` |
| 3（最高） | 读数录入值 | `readings.extra`，数据页每个读数的变量输入框 |

合并时高优先级来源**覆盖**低优先级；但常量和录入值只收集公式中实际出现的变量。缺少变量时该读数显示"缺少V/c"并列出缺失项，不算结果。

要点：

- `m`、`v` 是保留变量，方法常数里不允许再定义（保存时报"m 和 v 固定取样品称样量与定容体积"）。
- **稀释倍数不参与公式**：`function` 类型不使用溶样的稀释因子（它只作用于 ppm/ppb 类型）。预置公式通过 `m` 直接对应原样，分取测定时应保证称样量口径一致，或在自定义公式中显式使用 `v` 和分取比例。
- 常数必须是公式中出现过的变量，否则保存报"公式中未使用这些常数"。

## 4. 数据页录入

数据页对 `function` 任务（`readingLineHtml` app.js:1787）：

- 自动解析公式变量（前端用正则提取标识符），对**未被常数、m、v 覆盖**的变量逐个渲染数字输入框，如 `V=<input> V0=<input> c=<input>`。
- 方法名旁边显示已固定的变量摘要（如 `M=65.38 m=2.0 v=250.0`）和"详情"按钮，弹窗显示公式、常数和方法说明。
- 每个读数行独立输入变量值；"+ 再测一遍"新增的读数有自己的变量。
- 与其他仪器一样支持平行读数"参与"勾选、任务级回标（标称/回读/带标）。

录入值在失焦后自动保存到对应读数的 `extra`，与原始读数同一套自动保存机制。

## 5. 结果聚合

`calc_result()`（app.py:356）：

1. 每个读数独立代入公式求值，得到各自的 %。
2. 有旧版"终值"标记（`is_final`）时优先采用终值集合；否则取勾选"参与"（`use_avg`）的读数。
3. 取算术平均，**乘回标系数**（勾选"带标"时 = 回读÷标称，或直接填的系数；未勾选 = 1）。
4. 结果 `round(…, 4)` 保留 4 位小数，单位恒为 `%`。
5. 无任何有效读数时返回缺失原因（"未选方法"、"缺少V"、第一条的公式错误等），不用 0 代替。

注意与 XRF 不同：滴定结果按**4 位小数**取整，不是 5 位有效数字。

## 6. 内置方法

种子数据见 `db_schema.py:591`（`INSERT ... WHERE NOT EXISTS`，不覆盖用户修改）。原子量按 CIAAW 标准原子量保留两位小数。通用骨架：

```text
w(%) = (V - V0) × c × M ÷ m ÷ 1000 × 100
```

量纲：(mL × mol/L = mmol) → ÷1000 = mol → ×M(g/mol) = g → ÷m(g) = 质量分数 → ×100 = %。

| 方法 | 公式 | 固定常数 | 说明 |
|------|------|----------|------|
| Zn-EDTA络合滴定 | `(V-V0)*c*M/m/1000*100` | `M=65.38` | EDTA:Zn = 1:1，参考 ISO 1784 |
| Fe-EDTA络合滴定 | 同上 | `M=55.85` | EDTA:Fe = 1:1，参考 ISO 4748 |
| Fe-重铬酸钾滴定 | `(V-V0)*c*6*M/m/1000*100` | `M=55.85` | 1 mol Cr₂O₇²⁻ 氧化 6 mol Fe(II)，参考 ISO 2597-1 |
| Cl-硝酸银滴定法 | `(V-V0)*c*M/m/1000*100` | `M=35.45` | Ag⁺:Cl⁻ = 1:1，铬酸钾指示剂，参考 GB/T 11896 |
| Al2O3-EDTA络合硫酸铜返滴定 | `(V-V0)*c*M/2/m/1000*100` | `M=101.96` | 过量 EDTA 用 CuSO₄ 返滴定（PAN）；V=EDTA 加入体积，V0=返滴体积，c 按两液等浓计；n(Al₂O₃)=n(净耗EDTA)/2，参考 GB/T 176 |
| Cu-碘量法 | `(V-V0)*c*M/m/1000*100` | `M=63.55` | Na₂S₂O₃:Cu = 1:1，淀粉指示剂，参考 GB/T 3884.1 |
| Ca-EDTA络合滴定 | `(V-V0)*c*M/m/1000*100` | `M=40.08` | pH>12.5（KOH），钙黄绿素类指示剂，结果以 Ca 计，参考 GB/T 176 |
| 酸碱滴定(通用) | `(V-V0)*c*M/m/1000*100` | 无 | `M` 由操作者按读数录入；非 1:1 反应取克当量；参考 GB/T 601 |
| 有效氯-碘量法(次氯酸钠) | `(V-V0)*c*M/m/1000*100` | `M=35.45` | 结果以有效氯(Cl 计)%，1 mol Na₂S₂O₃ ≈ 1 mol Cl，参考 GB/T 19106 |

另有一个 `xrf` 类型方法 `WUNI0820`（无公式），与滴定无关。

## 7. 自定义方法

设置页"滴定方法"（`POST /api/methods`，需设置维护能力）：

- 名称、公式、固定常数（`M=65.38` 式写法或 JSON）、备注。
- 校验：公式语法（第 2 节）、常数必须是数字且都在公式中出现、常数不得定义 `m`/`v`、备注 ≤2000 字。

自定义时的注意事项：

1. **量纲自检**：公式输出就是原样质量分数 %，所有换算（体积→摩尔→质量→分数）必须写进公式。骨架之外的系数（化学计量比、克当量）直接乘在 `c` 后面，如重铬酸钾法的 `*6`。
2. **空白方向**：预置方法统一 `V - V0`；返滴定应把"加入量 − 剩余量"折算进变量含义并在方法说明中写清。
3. **浓度口径**：`c` 必须是 mol/L；当量浓度 N 不能直接当 `c` 用（相差 n 倍），须先换算。
4. **报告组分**：Ca / CaO / CaCO₃、有效氯 / NaClO 等口径由 `M` 决定，方法名必须与口径一致；需要多个口径就建多个方法。
5. **稀释与分取**：系统不自动乘稀释倍数；若溶样定容后只移取部分滴定，公式需自行引入分取比例（可利用保留变量 `v` 与自定义变量），或让 `m` 只对应被滴定部分的称样份额，并在方法说明中写清约定。
6. 每个新方法正式使用前，用有证标样和一个人工计算案例核对。
