# 前 83 个元素原子量

> 数值采用常用标准原子量；对无稳定同位素的 Tc、Pm，采用常用质量数 98、145，便于脚本计算。

该表已作为数据库参考数据写入 `chemical_elements`，字段为原子序数、元素符号、中文名、原子量和质量数标记。当前业务尚未读取该表；Tc、Pm 的 `is_mass_number` 为 `1`，避免后续计算误把质量数当作标准原子量。

常见报告氧化物另存于 `common_oxides`，目前收录 68 种，包括 FeO/Fe2O3/Fe3O4、MnO/MnO2/Mn3O4、Al2O3、SiO2、CaO、MgO、Na2O、K2O 和稀土氧化物等。表中保存元素与氧的化学计量数，并由本页原子量自动生成摩尔质量、元素质量分数和元素转氧化物系数。报告口径设计见 [`xrf-element-oxide-reporting.md`](xrf-element-oxide-reporting.md)。
