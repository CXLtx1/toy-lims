# LabFlow 操作手册

> Laboratory MES · 实验室执行系统  
> 项目名：toy-lims  
> 文档日期：2026-09-02

## 1. 手册说明

LabFlow 并不是一个完整的Lims系统，它只是一个实验室执行系统，可以理解为实验室管理系统的一个核心组件。

系统仍会持续进行更新，若无法连接大概率是在进行维护，可以联系开发人员。

本手册以当前网页和程序实际行为为准。实验方法、前处理条件、终点判断和质量控制要求仍以实验室现行标准为准，在正式版Lims发布之前请以纸质版为准。

一些强调，下面也会提到：
1. **按钮可见不代表当前用户具备权限，服务器会在执行时再次检查。**
2. **每个用户的密码必须不同。**
3. **有的地方是自动保存的而有的地方是需要手动保存的，请务必注意。新建好后请确认是否新建成功。**
4. **请分清楚终端与用户的区别。用户密码和终端密码用途不同，不应混用或共用。**
5. **有时页面内容需要一些时间进行加载，如样品页，这是正常的，如出现无法加载或出现报错弹窗，立刻联系开发或运维人员。**
6. **各个仪器客户端软件需要手动打开，若出现离线，可以点击客户端软件的重新连接按钮。**
7. **新建样品时水分、煤、石膏、碳硫分析和量热请选择其他。**
8. **分析项目框建议使用空格。可以输入氧化物等化合物。**
9. **一个样品送到实验员有几个溶样就建几个溶样。表格里的请务必与现实一一对应。**
10. **如有必要，可以将溶样名改为玻璃器皿上的编号。**
11. **一般情况没有必要填XRF的紫色框。**
12. **其他样不能启用 XRF，也不能与常规样互相转换。已有专项数据后不能直接更换专项方法。**
13. **并不建议在设置页建模板，建议在来样的详细清单选择保存当前方案。**
14. **LabFlow 提供权限控制、密码验证、审核状态和审计轨迹，但当前不等同于监管定义下的合规电子签名系统**。
15. **为了方便使用，建议学习使用快捷键。ESC键在不同场景下有不同的作用。按数字键切换页务必注意光标是否在输入框中，按ESC即可将光标从输入框中移出。**
16. **建议使用标签功能，方便使用和进行任务分配。样品小类（如 #实验样），分组操作（如 #二组）建议使用，但并不强制。**
17. **请注意分析项目的顺序和单位，这些都可以设置，且有模板可以使用。**
18. **请有在设置页添加内容的勇气，如果你有需求，请务必考虑。模板能提高使用效率，请务必灵活运用。**
19. **如果有问题请务必询问其他实验员或与开发者交流，如有新功能或问题务必与开发者沟通。**
20. **最后，效率是首位的，在效率的基础上尽量多使用本系统。无纸化并不是这个系统的目的，安全也不是这个项目的目的，合规性更不是这个项目的目的，效率是这个项目的目的。**

### 1.1 九个功能页

| 页面 | 主要用途 |
|---|---|
| 来样 | 登记样品，设计溶样、稀释、项目和仪器方案 |
| 数据 | 推进制样和测量，录入原始数据，关联 XRF 扫描 |
| 仪器 | 查看标准仪器客户端和 XRF 状态、扫描记录 |
| 结果 | 汇总计算结果，调整参与项，审核或特权补录 |
| 报告 | 编排已审核样品，保存票面信息，打印或导出 |
| 审计 | 查询操作人、时间、原因及修改前后内容 |
| 用户 | 管理用户、能力、实体终端和密码 |
| 设置 | 管理项目、仪器、方法、模板和报告版式 |
| 关于 | 查看快捷键说明 |

### 1.2 全流程总览

```text
登录终端
  → 登记样品并配置检测方案
  → 制样完成
  → 开始测量
  → 录入常规/专项数据并关联 XRF
  → 全部任务完成，系统自动转为待审核
  → 审核确认
  → 编排、保存并打印报告
  → 审计追溯与归档
```

### 1.3 推荐阅读路径

- 日常收样和分析人员：重点阅读第 2 至第 8 章。
- 审核和报告人员：重点阅读第 3、8、9、11、14 章。
- 系统管理员：在业务章节之外，重点阅读第 10 至第 13、16、17 章。
- 新用户培训：先通读第 1 至第 3 章，再按第 18 章检查表完成一份测试样品全流程。

## 2. 登录、身份与权限

### 2.1 访问与首次初始化

使用实验室管理员提供的局域网地址，通过最新版 Edge 或 Chrome 打开系统。正常情况下首先进入终端登录页。

全新系统第一次打开时进入初始化页：

1. 填写首个用户的显示姓名和用户密码。
2. 分别设置初始标准终端“二组”和管理终端的密码。
3. 两个终端使用不同密码。
4. 提交后返回登录页，按实际入口登录。

已有用户的旧数据库升级时，初始化只要求具备用户管理能力的现有用户验证密码并建立终端，不会重建或删除原用户。

### 2.2 三种登录入口

#### 标准终端

适合实验室共用电脑。

1. 在登录页选择“标准”。
2. 选择当前实体终端。
3. 输入终端密码进入系统。
4. 浏览、导出和查看内容不需要用户授权。
5. 第一次修改数据时，在授权窗口输入个人用户密码。

授权成功后，系统按该用户的能力执行并记录真实操作者。最后一次成功写操作后 2 分钟没有继续修改，授权自动失效；也可点击页头“结束授权”立即清除。

#### 个人终端

适合个人电脑或需要明确个人身份的场景。

1. 在登录页选择“个人”。
2. 输入用户名和用户密码。
3. 登录期间始终按该用户的能力操作。

个人终端不需要选择实体设备，普通写操作也不重复弹出授权框。

#### 管理终端

适合受控的管理设备或软件开发电脑。

1. 在登录页选择“管理”。
2. 选择管理终端并输入终端密码。
3. 登录后具有全部操作能力。

管理终端的修改以“管理员 · 终端名称”记录，不代表某个自然人。涉及正式业务责任时，优先使用个人身份或标准终端用户授权。

### 2.3 用户能力

系统不使用固定角色，而是为用户组合以下能力：

| 能力 | 典型操作 |
|---|---|
| 样品登记与修改 | 新建、修改、复制样品，完成制样，作废早期样品 |
| 检测数据录入 | 开始测量，录入读数，关联 XRF，退回补测 |
| 报告编辑 | 保存报告票面信息和报告编排 |
| 审核退回与手工结果补录 | 退回已审核样品，补录或恢复系统结果 |
| 审核与发布 | 审核确认样品 |
| 基础设置维护 | 维护项目、仪器、方法、模板和版式 |
| 用户管理 | 新增、修改、启停用户及重置密码 |
| 终端管理 | 新增、修改、排序和启停实体终端 |

**按钮可见不代表当前用户具备权限，服务器会在执行时再次检查。**

### 2.4 特权操作

以下操作必须填写原因，并再次输入具备“审核退回与手工结果补录”能力的用户密码：

- 将已审核样品退回待审核；
- 手工补录最终结果；
- 删除手工补录并恢复系统计算。

特权验证仅用于当前指定操作，短时有效并在使用后失效。

### 2.5 密码与退出

- **用户密码和终端密码用途不同，不应混用或共用**。
- 标准终端依靠唯一用户密码识别操作者，启用用户应使用互不相同的密码。
- 点击“结束授权”只清除当前用户授权，不退出终端。
- 点击“退出终端”返回登录页。
- 旧密码可继续使用，成功验证后系统会自动升级其存储方式，用户无需改密。

## 3. 样品状态与控制规则

### 3.1 状态含义

| 页面状态 | 含义 | 主要下一步 |
|---|---|---|
| 未制样 | 样品已登记，尚未确认制样 | 制样完成 |
| 未测量 | 制样已完成，尚未开始检测 | 开始测量 |
| 测量中 | 正在录入，或仅部分任务完成 | 继续录入 |
| 待审核 | 全部任务已有有效结果 | 审核确认 |
| 已审核 | 结果已审核发布，数据锁定 | 编排报告 |
| 已作废 | 业务终止，记录保留 | 仅查询 |

### 3.2 正常流转

```text
未制样 → 未测量 → 测量中 → 待审核 → 已审核
```

- “测量中 → 待审核”由系统在全部任务完成后自动推进。
- 启用 XRF 的样品必须关联扫描，XRF 任务才算完成。
- 每次状态变化均记录操作者、终端、时间和审计信息。

### 3.3 退回、作废与锁定

- 未测量可退回未制样。
- 测量中可退回未测量。
- 待审核可退回测量中补测。
- 已审核只能通过特权操作退回待审核。
- 未审核样品可作废，必须填写原因；作废不会物理删除历史数据。
- 退回不会自动删除已录入的原始值。
- 已审核或已作废后，样品方案、读数、参与状态、XRF 关联和报告口径均锁定。

如需修改已审核数据，应先特权退回，再按正常流程修改和重新审核。

## 4. 来样登记

### 4.1 查询和筛选

来样页支持：

- 按“全部、固体样、液体样、水质样、其他样”筛选；
- 按来样序号、样品名称或分析项目搜索；
- 使用标签筛选同时锁定多个条件；多选时只显示包含全部所选标签的样品。标签筛选写入网址的 `tag` 参数，并随来样、结果、报告页面切换保留；
- 显示或隐藏已作废样品；
- 设置每页 20、50、100 或 200 条；
- 按日期范围导出当前筛选条件下的样品总览。

点击样品卡可展开资料；“录数据”进入数据页；“复制新建”以现有方案为基础创建新样品。

标签筛选采用 AND 规则。例如同时选择 `#实验样` 和 `#二组`，只显示同时拥有这两个标签的样品。网址形式为 `?tag=实验样&tag=二组`；通过该网址进入系统后，点击“新建样品”会默认把这些标签加入新样品。

### 4.2 新建常规样品

1. 点击“+ 新建样品”。
2. 填写“来样序号”，例如 `RY2888`。
3. 填写“样品名称”，可从历史内容中选择。
4. 可输入新标签或从已有标签中选择多个标签，例如 `#实验样`、`#二组`。
5. 选择固体、液体或水质类型。**水分、煤、石膏、碳硫分析和量热请选择其他。**
6. 可选择模板并点击“应用”。
7. 输入溶样后待测项目。
8. 如需 XRF，勾选“打荧光”，选择 XRF 方法和默认报告项目。
9. 配置一路或多路溶样、稀释、测定项目及仪器。
10. 核对无未识别项目、未分配仪器或缺失公式方法。
11. 点击“创建样品”。

系统创建不可重复的正式 LIMS 编号，格式类似：

```text
20260902-001
```

### 4.3 输入分析项目

项目可使用**逗号、中文逗号、顿号、分号或空格**分隔，例如：

```text
Ag, Cu Fe；pH 
```
下面也可以：
```text
tOc H CAO fe2o3 sIo2 cACo3
```
**建议使用空格。可以输入氧化物等化合物。**

- 识别成功的项目显示为正常标签。
- 未识别项目显示红色问号，不会建立检测任务。
- 大小写不敏感，重复项目自动去重。
- 缺少项目时，应先到“设置 → 分析项目”维护，再返回登记。

### 4.4 配置溶样和仪器

每一路溶样可独立设置：

- 溶样名称；
- 固体样称样量 g；
- 固体样首次定容体积 mL；
- 最多 8 级二次稀释；
- 本路实际测定项目；
- 每个项目使用的仪器；
- 公式类仪器使用的分析方法。
- 液体没有称样量，也没有定容。如有必要可以填写密度。

项目分配操作：

1. 点击一个或多个项目标签。
2. 将所选项目拖到目标仪器，或点击目标仪器区域。
3. 不在该路测定的项目移到“不测”。
4. 公式类任务继续选择具体公式方法。

仪器必须在设置中配置为“可测该项目”，否则不会成为可选目标。

二次稀释以实际移取和定容表示，例如 `5/100` 表示 20 倍。多级稀释的总倍数为各级倍数乘积。

系统自动生成的溶样名称通常为：

```text
首个项目.来样序号*总稀释倍数
```

名称可直接修改，不影响计算。

### 4.5 四类样品的区别

#### 固体样

- 填写称样量、首次定容和后续稀释。
- ppm 类结果通常换算为质量分数 `%`。

#### 液体样

- 不填写称样量和首次定容。
- 保留处理路线、稀释、项目和仪器分配。
- ppm 类结果按稀释倍数换算为 `mg/L`。
- “液体密度”可留空；填写以 `g/mL` 表示的密度后，结果页才开放浓度单位与质量单位之间的换算。

#### 水质样

- 采用常规液体检测流程，可配置项目、仪器、公式方法和 XRF。
- 不填写称样量和首次定容。
- 报告页使用独立的“污水处理分析原始记录”和“废水分析报告票”。
- 水质样应与非水质样分批打印。

#### 其他样

其他样采用专项检测，不建立常规溶样和元素任务。当前包括：

- 水分分析；
- 煤/炭精分析；
- 石膏分析；
- 碳硫分析；
- 量热分析。

**其他样不能启用 XRF，也不能与常规样互相转换。已有专项数据后不能直接更换专项方法。**

### 4.6 模板和溶样组合

样品模板适合重复性较高的完整检测方案，可保存样品名称、多个标签、类型、项目、默认仪器、公式方法、XRF 设置及多路溶样。来样序号不会保存进模板。

- 新建时选择模板并点击“应用”。
- 展开已有样品后，可将当前方案另存为模板。
- 应用模板时会带入模板的样品名称和标签；如果新建样品已从网址继承筛选标签，两组标签会合并去重。
- 修改模板不会追溯修改已经创建的样品。

溶样组合只保存多路物理制样结构，例如称样、定容和稀释链。选择组合后可一次追加多路，但仍需核对项目和仪器分配。

**并不建议在设置页建模板，建议在来样的详细清单选择保存当前方案。**

### 4.7 修改、复制和作废

- 展开样品卡后可直接修改未锁定样品。
- 修改时，未发生变化的任务及其读数会保留。
- 改变仪器或方法可能清空对应任务原始数据，应先确认影响。
- “复制新建”继承原方案，但生成新的样品和 LIMS 编号。
- 作废必须填写原因，作废后记录仍可在勾选“显示已作废”后查询。

## 5. 制样与数据录入

### 5.1 进入数据页

可从样品卡点击“录数据”，也可打开“数据”页后选择当前样品。页头会持续显示当前样品，点击可返回来样资料。

### 5.2 完成制样

样品处于“未制样”时：

1. 核对每一路称样、定容、稀释、项目和仪器。
2. 完成实验室实际制样操作。
3. 点击“制样完成”。

状态转为“未测量”。

### 5.3 开始测量

样品处于“未测量”时：

1. 再次核对样品、仪器和分析方法。
2. 点击“开始测量”。
3. 状态转为“测量中”，录入控件解除只读。

### 5.4 常规原始值

任务按仪器分组显示，每一行对应一个溶样下的一个分析项目。

1. 在第一遍输入原始值。
2. 输入框失焦后自动保存，行末显示保存状态。
3. 需要平行测定时，点击“+ 再测一遍”。
4. 多遍读数使用“参与”复选框决定是否纳入结果。
5. 可删除错误的某一遍读数。

系统先分别换算参与读数，再对参与结果取平均。只有一遍时默认参与。

### 5.5 公式方法数据

公式任务会显示该方法需要的变量，而不是单一浓度值。

- `m` 自动取固体称样量；
- `v` 自动取首次定容体积；
- 方法中配置的常数自动带入；
- 其余变量由操作者逐遍填写；
- 点击“详情”可查看公式、单位、常数和说明；
- 变量未填齐时不生成该遍结果。

公式结果按参与读数平均，再应用回标系数，最终保留 4 位小数。具体变量含义和实验条件以该方法说明及 SOP 为准。

### 5.6 回标数据

任务可填写“标称值”“回读值”并勾选“带标”。当前系统使用：

```text
回标系数 = 标称值 ÷ 回读值
校正结果 = 原计算结果 × 回标系数
```

例如标称值为 10、回读值为 9，结果乘以约 `1.1111`。录入前应确认所用质控口径与实验室规定一致。

### 5.7 专项数据

其他样在数据页显示对应专项表单：

- 白色字段由操作者填写；
- 灰色字段由系统公式计算；
- 带 `*` 的必填原始字段全部填写后，任务才算完成；
- 备注可按实际情况填写；
- 字段失焦后自动保存并重新计算。

### 5.8 表格式批量操作

| 操作 | 效果 |
|---|---|

| `Shift` | 扩展选区 |
| `Ctrl+C` | 复制为制表符文本 |
| `Ctrl+V` | 从 Excel 粘贴 |
| 方向键 | 在单元格间移动 |
| `Ctrl+D` | 使用首格向下填充 |

批量粘贴后应逐行核对保存状态和计算结果。

## 6. XRF 操作

### 6.1 来样时设置

勾选“打荧光”后：

1. 选择启用的 XRF 方法。
2. 填写默认报告项目，或使用“元素口径”“氧化物口径”快捷项。
3. 核对同一元素族需要报告元素还是氧化物。

仪器返回的全部定量项目都会保存；默认报告项目仅决定初始参与和报告口径。

### 6.2 XRF 仪器端操作

1. 启动 XRF 客户端并确认已连接 LabFlow。
2. 在置顶待测窗口查找目标任务。
3. 点击样品名称复制，名称可能重复时优先使用 LIMS 编号核对。
4. 在 OXSAS 中按实验室操作规程进样和测量。
5. 普通定量完成或 UniQuant 人工处理完成后，客户端同步结果到 LabFlow。
6. 回到网页数据页或仪器页，核对并手工关联扫描。

客户端只读 OXSAS 数据，不创建或修改 OXSAS 批次和数据库内容。需要补查历史结果时，可在客户端主窗口执行“立即补传并同步”。

### 6.3 扫描上传原则

OXSAS 普通定量和处理完成的 UniQuant 结果上传后，统一先进入“未关联扫描池”。系统不会根据 OXSAS 样品名、LIMS 编号或客户端样品 ID 自动认领，必须由操作人员核对后手工关联。

### 6.4 在数据页关联

1. 打开当前样品的数据页。
2. 在 XRF 面板搜索原始样品名、方法、批次或扫描编号。
3. 展开候选扫描并核对时间、方法、批次和组成。
4. 点击“关联当前样品”。
5. 如关联错误，先点击“解绑当前扫描”，再重新关联。

每个 LIMS 样品最多关联一条扫描，一条扫描不能关联多个样品。已审核或已作废样品不能关联或解绑。

### 6.5 仪器页监控

“仪器”页可查看：

- XRF 在线、离线、待机、测量、上传或错误状态；
- 当前样品、方法、批次、位置和开始时间；
- 普通定量和 UniQuant 扫描历史；
- 已关联或未关联筛选；
- 扫描类型、搜索和分页；
- 全部 Wt% 组成；
- 直接关联或解绑样品。

仪器页约每 2 秒刷新一次。

### 6.6 调整报告口径

结果页 XRF 区域的“口径”功能按元素族设置：

- 是否参与最终报告；
- 报元素还是氧化物；
- 同一元素族只能选择一个最终目标。

仪器直接给出目标口径时优先使用直出值；缺少目标时，系统可按已维护的化学计量系数换算并标明来源。多价态不会自动猜测。直出值与换算值偏差超过 1% 时应人工核对；没有可靠来源时保持缺失，不以 0 代替。

## 7. 标准仪器客户端

标准客户端适用于 ICP-OES、ICP-MS、AAS、离子电极和 pH 等单值仪器。公式类任务仍在网页中录入。

### 7.1 日常录入

1. 启动为当前仪器配置好的客户端。
2. 使用具备“检测数据录入”能力的用户密码登录。
3. 从任务列表选择待测样品和项目。
4. 未开始测量的样品可在主窗口确认“开始测量”。
5. 输入读数，输入后项目自动勾选。
6. 按 `Enter` 跳到下一项。
7. 按 `Ctrl+Enter` 提交当前已勾选读数。
8. 提交后核对成功提示和网页结果。

主窗口显示完整任务和已有读数；置顶浮窗只显示尚无读数且可录入的项目。客户端 10 分钟无录入活动后要求重新登录。

### 7.2 注意事项

- 客户端固定绑定一台 LIMS 仪器，不要自行更改程序目录配置。
- 一次提交中的读数整体保存；网络重试不会重复创建同一批读数。
- 仪器客户端只通过 HTTP 接口连接 LabFlow，不直接操作数据库。
- 客户端异常时可回到网页数据页继续录入，并在仪器页检查在线状态。

## 8. 结果与审核

### 8.1 查找和展开结果

结果页显示未测量、测量中、待审核和已审核样品。可搜索、使用与来样页相同的多标签筛选、分页并点击样品行展开；多个样品可以同时展开。

- 常规结果按项目卡片显示最终值和各溶样/仪器明细。
- XRF 使用紧凑组成网格。
- 专项样显示专项项目、结果和单位。
- `Esc` 可从最近展开的样品开始逐个收起。

### 8.2 选择结果显示单位

常规项目卡片紫色标题条上的单位可以**点击切换**；XRF 最终组成中的每个项目也可独立切换。单位选择同时作用于结果页、报告预览和报告 Excel，不会改写仪器原始值。

- 固体和 XRF：`%`、`ppm`、`ppb`。
- 液体：`g/L`、`mg/L`、`ug/L`。
- 液体填写密度后：额外开放 `%`、`ppm`、`ppb`。
- 未填写液体密度时，系统不允许在体积浓度与质量分数之间换算。
- 已出报告或已作废样品不能再修改结果单位。

### 8.3 调整参与最终值

同一项目存在多条溶样或仪器结果时，可勾选哪些任务参与最终平均。调整后应核对卡片头最终值和计算明细。

已审核样品不能调整，必须先特权退回。

### 8.4 审核确认

审核前至少核对：

- 样品身份、类型和状态正确；
- 所有项目均有有效结果；
- 平行读数参与选择合理；
- 回标方向和数值正确；
- XRF 扫描属于当前样品；
- XRF 元素/氧化物口径正确；
- 单位、公式方法及异常说明正确。

样品处于“待审核”时点击“审核确认”。审核后系统记录审核人，并锁定数据和报告口径。

### 8.5 特权退回

已审核结果需要修改时：

1. 点击“特权退回审核”。
2. 填写明确原因。
3. 再次输入具备特权能力的用户密码。
4. 修改数据或方案。
5. 重新完成并审核。

### 8.6 手工补录最终结果

仅常规样在待审核或已审核阶段可使用：

1. 进入手工补录。
2. 填写项目、结果文本、单位和说明，至少一条。
3. 填写补录原因。
4. 完成特权密码验证。

手工结果成为报告最终内容，但不会删除系统计算和原始记录。需要取消时使用“恢复系统计算”，同样要填写原因并再次验证。

### 8.7 导出结果报告

1. 勾选需要导出的样品；勾选可跨页保留。
2. 选择结果元素顺序模板。
3. 点击导出结果报告。

只可导出待审核或已审核的已完成常规样品，最多 200 个。不要混入未完成样品或专项样，否则整次导出会被拒绝。

## 9. 报告编排与输出

### 9.1 选择样品

报告页使用与来样页、结果页相同的标签筛选状态，可先通过多个标签锁定负责人员、实验组或临时批次，再勾选已审核样品。

报告页只显示已审核样品。

1. 搜索并勾选一个或多个样品。
2. 跨页勾选会保留，选中样品置顶显示。
3. 使用上下按钮调整整组顺序。
4. 水质样和非水质样不要混选，应分批打印。

### 9.2 票面信息

按整组填写：

- 报告版式；
- 来样单位；
- 报告编号；
- 分析日期；
- 分析人员；
- 审核人员，只读。

分析人员会依据所选样品的实际数据修改记录自动汇总，也可按业务要求核对。填写时预览实时变化；点击“保存整组票面信息”后写入全部已选样品。

当前版本点击打印时也会先保存整组票面信息，因此标准终端可能在打印前要求用户授权。

### 9.3 编排报告结果

每个样品可：

- 调整项目上下顺序；
- 恢复默认项目顺序；
- 设置某项目是否打印；
- 展开查看溶样、仪器、方法、原始值和计算值。

“是否打印”只影响报告输出，不改变检测结果。

### 9.4 打印类型

- 分析报告票：A5 纵向；

打印前应在浏览器打印预览中核对纸张、方向、缩放、页码和分页，避免浏览器或打印机默认设置改变票面。

### 9.5 Excel 报告

报告页 Excel 为单样品导出，多选时不可用。文件包含：

- 分析报告；
- 原始分析记录；
- 计算明细。

该工作簿只用于查阅、传递或归档，不支持回传修改。

## 12. 用户与终端管理

### 12.1 用户管理

用户页可新增用户、修改用户名和姓名、配置能力、启停账号及重置密码。

管理约束：

- 用户名至少 3 个字符；
- 每个用户的密码**必须不同**；
- 不能停用当前个人登录账号；

- 终端名称必须唯一。
- 管理终端密码应与标准终端密码区分，并限制知悉范围。

## 13. 基础设置

设置修改会影响后续样品，应由指定管理员维护。历史样品通常保留创建时的方案，不会随设置自动改写。

### 13.1 报告版式

维护版式名称、公司中英文名、原始记录编号和报告票编号。系统至少保留一套版式。

### 13.2 结果元素顺序模板

用于结果页批量导出的扁平 Excel 列顺序。它不同于报告页单个样品的打印项目顺序。

### 13.3 分析项目

维护元素和指标，并为每个项目选择默认结果单位。“自动”保持系统现有规则：固体通常为 `%`，液体通常为 `mg/L`，XRF 为 `%`。默认单位与样品当前口径不兼容时，系统仍使用该样品可换算的原单位。删除项目可能影响仪器和模板关联，应先确认没有业务引用。

### 13.4 定容容量与稀释方式

- 新建溶样默认使用 250 mL。
- 稀释方式按“移取体积/再次定容体积”维护，例如 `5/100`。
- 系统自动计算倍数，例如 `100 ÷ 5 = 20`。
- 停用只影响新样品选项，历史样品继续保留原值。

### 13.5 溶样组合

将常用的多路称样、定容和多级稀释结构保存为组合。组合不包含完整项目和仪器方案，使用后仍须核对分配。

### 13.6 仪器与可测项目

新增仪器时应正确选择数据类型：

| 类型 | 典型含义 |
|---|---|
| xrf | XRF 质量分数直出 |
| ppm | ICP-OES、AAS 等 mg/L 原始值 |
| ppb | ICP-MS 等 μg/L 原始值 |
| mol | mol/L 直读 |
| percent | 百分数直读 |
| function | 公式变量计算 |
| ph | pH 直读 |

随后配置该仪器可测项目。数据类型决定录入形式、单位和换算规则，创建后不要随意修改。

### 13.7 分析方法

公式和 XRF 方法可维护名称、公式、输出单位、固定常数、说明、启停和显示顺序。

- 公式只允许数字、变量、括号和 `+ - * / **`。
- 变量区分大小写。
- `m` 和 `v` 由溶样方案提供，不能作为方法常数。
- 已被历史样品使用的方法应停用，不应删除。
- 正式目录方法的具体适用范围仍以 SOP 为准。

### 13.8 样品模板

模板可保存样品名称、多个标签，以及固体、液体或水质样的完整常规方案。设置页可新建、编辑和删除；其他样不使用常规模板。模板列表会显示预设样品名称和标签。

### 13.9 样品标签

设置页“样品标签”区域汇总当前正在使用的标签及关联样品数量。标签不在设置页单独创建，而是在来样详情中随样品添加；最后一个使用该标签的样品移除标签后，该标签会自然从汇总和历史选项中消失。

## 14. 计算口径速查

### 14.1 固体 ppm 类

```text
结果(%) = 原始浓度(mg/L) × 定容体积(mL) × 总稀释倍数
          ÷ 称样量(g) ÷ 10000
```

### 14.2 固体 ppb 类

```text
结果(%) = 原始浓度(μg/L) × 定容体积(mL) × 总稀释倍数
          ÷ 称样量(g) ÷ 10000000
```

### 14.3 液体样

```text
结果 = 原始值 × 总稀释倍数
```

ppm 类输出 `mg/L`；ppb 类保持 ppb。

### 14.4 XRF 与 pH

- XRF 原始值直接作为质量分数 `%`，口径换算另按元素/氧化物系数处理。
- pH 结果等于原始 pH 值。

### 14.5 公式方法

每遍数据独立代入公式，参与读数取平均，再乘回标系数。方法本身决定输出单位，系统不会在公式结果后额外进行固液换算。

## 16. 常见问题与处理

### 16.1 点击保存后提示无权限

- 标准终端：输入具备对应能力的用户密码。
- 个人终端：联系管理员补充必要能力，或由有权限人员操作。
- 不要借用他人密码绕过审计身份。

### 16.2 项目显示红色问号

项目未在基础设置中登记，或输入名称不一致。到“设置 → 分析项目”确认后重新输入。

### 16.3 项目无法分配到目标仪器

到“设置 → 仪器与可测项目”确认该仪器已勾选此项目；公式仪器还必须选择启用的公式方法。

### 16.4 样品一直停留在测量中

逐项检查：

- 是否有任务没有有效读数；
- 多遍读数是否至少有一遍勾选参与；
- 公式变量是否填写完整；
- 专项必填字段是否齐全；
- XRF 样品是否已关联扫描。

### 16.5 XRF 搜不到或不能关联

- 确认客户端已上传扫描；
- 尝试按原始样品名、方法、批次或扫描编号搜索；
- 确认扫描尚未关联其他样品；
- 确认当前样品尚未关联另一条扫描；
- 确认样品不是已审核或已作废状态。

### 16.6 Excel 提示更新标记过期

说明样品导出后已被其他人修改。重新导出最新工作簿，在新文件上修改后再上传，不要强行使用旧文件。

### 16.7 Excel 上传被拒绝

检查文件类型、说明页、工作表名、表头、ID、JSON 和数据区公式。不要用另存工具破坏工作簿结构。

### 16.8 报告打印按钮不可用

- 确认样品均已审核；
- 不要混选水质和非水质样品；
- Excel 报告仅支持单个样品；
- 核对浏览器是否拦截打印或弹窗。

### 16.9 页面内容自动变化

系统会检测其他终端的数据修改并刷新当前页面。输入框聚焦时会暂停重绘，失焦后可能显示最新数据。多人同时操作时，应在覆盖或审核前重新核对。

### 16.10 误录或误审核

- 未审核：按状态退回并修正，已有读数不会自动删除。
- 已审核：使用特权退回，填写真实原因，再修改和重新审核。
- 不要作废后重新建样来掩盖可纠正错误；所有纠正均应保留审计链。

## 17. 日常管理与数据安全

### 17.1 推荐日常检查

#### 每班或每日

- 检查仪器页客户端在线状态和未关联 XRF 扫描；
- 检查测量中、待审核样品是否积压；
- 检查异常审计记录和作废原因；
- 确认报告编号和分析日期填写完整。

#### 定期

- 复核用户启用状态和能力是否符合岗位；
- 停用离岗用户并更换受影响的终端密码；
- 检查项目、仪器、公式和模板是否仍适用；
- 验证 PostgreSQL 备份可用性和恢复流程。

### 17.2 备份原则

正式数据库使用 PostgreSQL，应由数据库服务器通过 `pg_dump`、计划任务或存储快照备份。

- Excel 导出不包含用户、密码、权限、审计和基础设置，不能替代数据库备份。
- 旧 `server/lims.db` 是迁移源或回退档案，不是正式运行库。
- 备份应保留多周期副本，并定期做恢复验证。

### 17.3 合规边界

LabFlow 提供权限控制、密码验证、审核状态和审计轨迹，**但当前不等同于监管定义下的合规电子签名系统**。需要法规合规时，应结合组织制度、计算机化系统验证、备份恢复、账号管理和电子签名要求另行评估。
