# 分析单生成器

独立的 .NET 10 WPF 小工具，与 toy-lims 服务端和网页完全无关。

- 使用程序内固定的账号密码，只读连接本机 OXSAS `ANALYSES` 数据库。
- 可按所选模板从数据库结果中选择 4A/4B 或 2B/2C 样品，不能手填；某一侧没有样品时勾选该侧“空白”，留空的半边整块输出为空白（样品名、元素和结果都不写入），两侧不能同时留空。
- 每个模板中两个样品的元素种类和顺序由 JSON 配置固定。
- 4A4B 模板将 OXSAS 的 Ag 百分值乘以 10000 转为 `ppm`，并保留两位小数（例如 `0.01219425162516%` 写为 `121.94ppm`）。
- 将 OXSAS 定量结果写入所选的 `4A4B.xlsx` 或 `2B2C.xlsx` 模板，可保存 xlsx 或直接交给 Windows 默认打印机。
- xlsx 默认输出到 exe 同目录下的 `分析单` 文件夹（不存在时自动创建），可在“浏览…”中改到任意位置。
- 直接打印依赖目标电脑安装 Microsoft Excel。
- 发布版本不捆绑 .NET，目标电脑需安装 .NET 10 Desktop Runtime。

新增模板时，将 xlsx 和同名 JSON 放进 templates 文件夹即可。JSON 需要配置源工作表、
日期与时间单元格、打印区域，以及每个样品位置固定的元素种类、顺序和单元格范围。
`resultFormats` 可按项目配置输出倍数、单位后缀和小数位数。
